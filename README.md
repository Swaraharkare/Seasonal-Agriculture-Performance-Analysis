# Seasonal-Agriculture-Performance-Analysis
A data-driven Python EDA pipeline using Pandas, NumPy, Matplotlib &amp; Seaborn to analyze 4,000 farm records across Kharif, Rabi &amp; Zaid seasons. Features robust data cleaning, custom performance KPIs (Profit Margin %, Water Efficiency), and multivariate correlation heatmaps to optimize crop selection and resource planning.
